Concept 003

Number Representation

I · Origins
一1 · MARK三3 · ALGORITHM四4 · PRINT
一

1 · MARK

Egypt/Eastern MediterraneanChinaMesopotamia

Tallies record quantity; representation invents marks that stand for numbers when the things are gone. Egyptian hieroglyphic numerals (from about 3000 BCE) used distinct signs for 1, 10, 100, 1,000—additive, not place-value. Chinese Shang oracle bones already show decimal groupings. Roman numerals later gave Europe a durable public script. Each system answers: how do you ship “seven” without seven goats?

三

3 · ALGORITHM

IndiaBaghdad/Islamic-PersianChina

Positional notation—Hindu–Arabic digits with a true zero—changed what a written number could do. Indian mathematicians developed the system; scholars in the Baghdad orbit explained it across languages; Chinese rod numerals already practiced place-value on boards. Representation became a compact machine for arithmetic. Algorithms for roots, multiplication, and accounting rode on those digits.

四

4 · PRINT

Italian Commercial/RenaissanceAtlantic Scientific Revolution

Printing put numeral systems into every counting-house and schoolbook. Standardized Arabic digits, Renaissance commercial manuals, and later algebraic typefaces made one shared visual language for number. Charts and primers no longer depended on a single scribe’s hand. When marks copy by the thousand, debate shifts from which symbols count to which calculations they should support.
