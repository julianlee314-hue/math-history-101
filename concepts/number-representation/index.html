Concept 003

Number Representation

I · Origins
一1 · MARK三3 · ALGORITHM四4 · PRINT
一

1 · MARK

Egypt/Eastern MediterraneanChinaMesopotamia

Tallies record quantity; representation is inventing marks that stand for numbers even when the things are gone. Egyptian hieroglyphic numerals (from about 3000 BCE) used distinct signs for 1, 10, 100, 1,000 and up—still additive, not place-value. Chinese Shang oracle bones (late second millennium BCE) already show decimal groupings. Roman numerals later gave Europe a durable, if clumsy, public script for civic stone and ledger alike. Each system answers the same problem the tally began: how do you make “seven” travel without seven goats? Writing number down is civilization’s way of shipping quantity through time.

三

3 · ALGORITHM

IndiaBaghdad/Islamic-PersianChina

Positional notation—especially the Hindu–Arabic digits with a true zero—changed what a written number could do. Indian mathematicians developed the system; scholars in the Baghdad orbit transmitted, explained, and refined it for new audiences across languages; Chinese rod numerals had already practiced place-value on boards for rapid calculation. Representation stopped being only a label on a jar and became a compact machine for arithmetic. Algorithms for roots, multiplication, and accounting rode on those digits. Once the marks carried place, the marks could carry method, and clerks could share procedures instead of only shared symbols.

四

4 · PRINT

Italian Commercial/RenaissanceAtlantic Scientific Revolution

Printing multiplied numeral systems into every counting-house and schoolbook. Standardized Arabic digits, commercial arithmetic manuals in Renaissance Italy, and later typefaces for algebraic symbols made one shared visual language for number across Europe and far beyond. Charts, ledgers, and primers no longer depended on a single scribe’s hand or a local numeral fashion. When representation can be copied by the thousand, a civilization stops arguing about which marks count and starts arguing about what calculations those marks should support. Print turned number symbols into infrastructure.
