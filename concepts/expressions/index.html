Expressions

IV · Renaissance
三3 · ALGORITHM四4 · PRINT
三

3 · ALGORITHM

Baghdad/Islamic-Persian

An expression is a recipe for a value built from numbers, operations, and later letters—before it is set equal to anything. Rhetorical algebra spoke expressions in sentences; symbolism compressed them. Parsing an expression is already mathematical literacy: reading structure, not only computing a final number. Expression slates invite building and reading that structure by hand.

四

4 · PRINT

Atlantic Scientific RevolutionItalian Commercial/Renaissance

Printed symbolic expressions with parentheses and operator conventions reduced ambiguity. School algebra became largely the art of transforming expressions. Typesetting rules quietly decided how generations would see mathematical phrases. Shared print conventions let distant classrooms rewrite the same expression the same way. Parentheses and operator precedence in type quietly taught generations how to parse math.
