Function Representation

V · Enlightenment

四

4 · PRINT

Atlantic Scientific RevolutionBritish Industrial/Engineering

Functions wear many costumes: formulas, tables, graphs, verbal rules. Print culture and engineering practice taught switching among them. Choosing the right costume often is the solution strategy. A function machine with a table and a graph nearby preaches multiple representations as one idea. Switching costumes—formula, table, graph—often is the solution strategy itself.

Software plots, interpolates, and symbolically differentiates representations on demand. Linked views make the old classroom advice interactive. Representation-changing remains the skill; silicon only shortens the redraw. Switching among formula, table, and graph is still the human move—machines just keep pace.
