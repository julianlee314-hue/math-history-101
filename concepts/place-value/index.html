Concept 005

Place Value

I · Origins
一1 · MARK三3 · ALGORITHM六6 · COMPUTE
一

1 · MARK

MesopotamiaChina

Place value means where a digit sits changes what it means—units, tens, sixties. Mesopotamia developed a sexagesimal (base-60) positional system by around 2000 BCE, with spacing and later a placeholder for empty places. Chinese counting rods gave East Asia a decimal place-value board from roughly the first millennium BCE. Ten ones become one ten: position does the work additive numerals struggled to do.

三

3 · ALGORITHM

IndiaBaghdad/Islamic-Persian

The Hindu–Arabic system, with a true zero placeholder, matured in India and spread west through the Islamic world by the 8th–9th centuries CE. Europe slowly left Roman numerals as merchants needed faster calculation. Addition, multiplication, and root extraction became compact because place value packed magnitude into columns. Al-Khwārizmī’s arithmetic tradition helped turn those columns into public procedure.

六

6 · COMPUTE

American/Global Computational

Binary, octal, and hexadecimal place-value systems power every digital computer. Registers still carry when a place overflows—the same column logic as clay tablets and rods, now switching in nanoseconds. Bit fields, memory addresses, and color channels all assume position multiplies meaning by a base. Place-value arithmetic never left the machine room; it only changed medium.
