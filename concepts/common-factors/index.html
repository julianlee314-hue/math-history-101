Common Factors

II · Classical
二2 · WRITE三3 · ALGORITHM
二

2 · WRITE

Greek/Hellenistic

Common factors—especially the greatest—measure shared structure between numbers. Euclid’s algorithm for the GCD is one of mathematics’ oldest surviving recipes still taught by name. Reducing fractions rests on this shared spine. Written proofs let strangers verify the common measure without standing in the original workshop.

三

3 · ALGORITHM

ChinaIndiaBaghdad/Islamic-Persian

Chinese remainder thinking and Indian number theory cultivated related modular and common-measure techniques. The Euclidean algorithm traveled and mutated across languages. Common factors became a workhorse for calendars, gear ratios, and fraction cleanup. Named steps made GCD a repeatable clerk skill, not only a theorist’s curiosity. Gear ratios and calendars both leaned on shared common-measure craft.
